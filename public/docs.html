API Documentation

Multi-provider REST scraper for AnimeSalt & WatchAnimeWorld.

Educational and research use only. Respect copyright laws and site terms of service. This project does not host media content.

Overview

All scrape routes live under /api and return JSON. Switch upstream sources with the global provider query parameter.

ParamValuesDefault
provider animesalt, watchanimeworld (aliases: waw, animeworld, salt, as) animesalt

Providers

IDSiteAliases
animesaltanimesalt.linksalt, as
watchanimeworldwatchanimeworld.topwaw, animeworld, awi

Access control

When CORS_ORIGIN is not *, requests must include a matching Origin or Referer header. Mismatches receive a 403 page.

Install

git clone https://github.com/itzzzdark/AnimeSalt-API.git
cd AnimeSalt-API
npm install
cp .env.example .env
npm run dev

Default base: http://localhost:3000

Health & providers

GET/api/health
curl http://localhost:3000/api/health
GET/api/providers
curl http://localhost:3000/api/providers

Home

GET/api/home provider

Newest drops, arrivals, movies, cartoons, most-watched lists.

curl "http://localhost:3000/api/home?provider=watchanimeworld"

Search

GET/api/search
ParamDescription
qFull search with images
suggestionFast title suggestions
 
curl "http://localhost:3000/api/search?q=naruto&provider=animesalt"
curl "http://localhost:3000/api/search?suggestion=naruto"

Details

GET/api/info/:id
curl "http://localhost:3000/api/info/spy-x-family"

Episodes

GET/api/episodes/:id/:season
curl "http://localhost:3000/api/episodes/spy-x-family/1"

Embed

GET/api/embed/:id

Player / iframe data for an episode slug.

curl "http://localhost:3000/api/embed/some-episode-slug"

Category

GET/api/category/*

Supports nested paths: movies, series, genre/sci-fi, language/hindi, network/…, franchise/…

curl "http://localhost:3000/api/category/movies?page=1"
curl "http://localhost:3000/api/category/genre/sci-fi?page=2"

Letter (A–Z)

GET/api/letter/:letter
curl "http://localhost:3000/api/letter/N?page=1"

Errors

  • 400 — validation / bad request
  • 403 — origin not allowed
  • 404 — route or resource missing
  • 500 — upstream scrape or internal failure
