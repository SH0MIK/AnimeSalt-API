🌐

Multi-provider

Switch between AnimeSalt and WatchAnimeWorld with a single ?provider= flag.

🎬

Home feeds

Newest drops, arrivals, movies, cartoons, and ranked most-watched lists in one call.

🔎

Search

Full page search with images, plus fast AJAX-style title suggestions.

📺

Details & seasons

Series and movie metadata, plus season episode lists ready for players.

🎥

Embed extraction

Pull player / iframe payloads for episode slugs without fighting the DOM yourself.

🛡️

Hardened edge

Helmet, CORS origin gate, compression, and HTTP retries for flaky upstreams.

Quick start
bash 
# clone & run
$ git clone https://github.com/itzzzdark/AnimeSalt-API.git
$ cd AnimeSalt-API && npm install && cp .env.example .env
$ npm run dev

# try it
$ curl "http://localhost:3000/api/home?provider=watchanimeworld"
$ curl "http://localhost:3000/api/search?q=naruto&provider=animesalt"
